Tad wrote `docs/patterns/accessibility-regression-suite.md` on 2026-06-01. The document describes every automated and manual check that forms an accessibility regression pass for James Nerf Squad. Automated tools covered are HTMLHint 1.9.2 (run via `npm run lint:html`), ESLint 10.4.1 (run via `npm run lint:js`), Pa11y 9.1.1, and axe-core CLI 4.11.3; the latter two are installed in `.github/accessibility-tools/` and run against a locally served instance of the game. Five manual checks cover keyboard-only navigation, the ARIA live-region spot-check against `#game-announcer`, the reduced-motion gate, the colour-contrast spot-check for the sprint 018 palette fixes, and font-rendering confirmation that no request reaches `fonts.googleapis.com`. The document includes a numbered run order, pass criteria that reference the Definition of Done in `docs/requirements.md`, a short section on adding new checks, and a section on recording exceptions that points to `docs/exceptions/` and `docs/accessibility.md`.
